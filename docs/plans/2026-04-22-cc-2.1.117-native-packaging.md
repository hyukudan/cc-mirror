# Claude Code 2.1.117 Native-Binary Migration Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Move cc-mirror all-in to Claude Code's native-binary packaging (2.1.113+), removing the legacy `cli.js` code paths, and upgrade the 4 existing mirrors to 2.1.117.

**Architecture:** Native-only. The `@anthropic-ai/claude-code` package now ships `bin/claude.exe` that a postinstall copies from a platform-specific `optionalDependency`. cc-mirror resolves that binary, the wrapper execs it directly (`exec "$BIN" "$@"`), and any step that rewrote `cli.js` (CliPatch, TeamMode `sU`) is deleted. A package-manager-agnostic postinstall fallback runs `node install.cjs` manually when pnpm blocks scripts.

**Tech Stack:** TypeScript ESM, `tsx` dev runner, `node --test` test framework, `esbuild` bundler, `pnpm`/`npm` for variant installs.

**Design doc:** `docs/plans/2026-04-22-cc-2.1.117-native-packaging-design.md`

## Task 3: Postinstall fallback

**Files:**
- Modify: `src/core/install.ts` (both sync and async install functions)

**Why:** pnpm v10 blocks postinstall scripts by default. Without this, install appears to succeed but `bin/claude` is never produced.

**Step 1: Write failing test**

Add to `test/core/install-postinstall-fallback.test.ts`:

```ts
import { test } from 'node:test';
import assert from 'node:assert/strict';
import fs from 'node:fs';
import path from 'node:path';
import { makeTempDir, cleanup } from '../helpers/fs-helpers.js';
import { runPostinstallFallback } from '../../src/core/install.js';

test('runPostinstallFallback executes install.cjs when binary missing', () => {
  const dir = makeTempDir();
  try {
    const pkgDir = path.join(dir, 'node_modules', '@anthropic-ai', 'claude-code');
    fs.mkdirSync(path.join(pkgDir, 'bin'), { recursive: true });
    fs.writeFileSync(path.join(pkgDir, 'package.json'), '{"name":"@anthropic-ai/claude-code"}');
    fs.writeFileSync(path.join(pkgDir, 'bin', 'claude.exe'), '#!/bin/sh\necho hi\n', { mode: 0o755 });
    fs.writeFileSync(
      path.join(pkgDir, 'install.cjs'),
      "const fs=require('fs'),p=require('path');const dst=p.join(__dirname,'bin','claude');fs.copyFileSync(p.join(__dirname,'bin','claude.exe'),dst);fs.chmodSync(dst,0o755);",
      { mode: 0o644 }
    );
    const ok = runPostinstallFallback(dir, '@anthropic-ai/claude-code');
    assert.equal(ok, true);
    assert.ok(fs.existsSync(path.join(pkgDir, 'bin', 'claude')));
  } finally {
    cleanup(dir);
  }
});
```

Run: `npm test -- --test-name-pattern="runPostinstallFallback"`
Expected: FAIL.

**Step 2: Implement**

Add to `src/core/install.ts`:

```ts
export const runPostinstallFallback = (npmDir: string, npmPackage: string): boolean => {
  const parts = npmPackage.split('/');
  const pkgDir = path.join(npmDir, 'node_modules', ...parts);
  const installScript = path.join(pkgDir, 'install.cjs');
  if (!fs.existsSync(installScript)) return false;
  const result = spawnSync(process.execPath, [installScript], {
    cwd: pkgDir,
    stdio: 'pipe',
    encoding: 'utf8',
  });
  return result.status === 0;
};
```

Update both `installNpmClaude` and `installNpmClaudeAsync` so the "binary not found after install" branch first calls `runPostinstallFallback`. If that returns true and the binary now exists, return success; otherwise throw the same error as before.

**Step 3: Run tests**

Run: `npm test -- --test-name-pattern="runPostinstallFallback"`
Expected: PASS.

**Step 4: Commit**

